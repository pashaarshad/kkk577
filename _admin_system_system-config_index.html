提现基础设置

extract_switch：提现开关。
recharge_num_is_withdrawal：充值大于多少允许提现,0代表不限制
extract_address_channel：只允许一个提现通道。开启后用户只能绑定trc20或者bep20其中一个地址
is_change_withdrawal_address：客户取款地址绑定后是否可修改。
is_repeat_withdrawal_address：客户取款地址是否能重复。
extract_input_contact：第一次提现是否要求输入联系方式。
auto_payment：是否自动出款。

出款金额设置

auto_payment_safety_value：自动出款金额安全值,当出款金额大于该值时,需要后台人工审核出款
min_extract_config：最小提现金额配置，选择全局由充值币种菜单配置控制，选择局部由vip配置菜单里控制。
24_hour_extract_status：是否开启24小时到账：24小时到账免手续费。
free_fee_num：单日免手续费笔数参数
total_free_fee_num：总免手续费笔数
extract_num_day：每日提现次数
is_upgrade_reset_extract：升级是否重置提现次数：比如会员充值VIP1做完任务后当天再充值VIP2是否提现次数重置。

collection_wallet：trc20归集地址
bep20_collection_wallet：bep20归集地址

注册配置

register_account_status：可选手机号或者邮箱注册。建议只能邮箱注册，并开启邮箱验证，可防刷防水军
is_verify_email_code：邮箱注册时是否需要验证邮箱。一条邮箱验证码将扣除0.02积分,开启后请注意积分不能为0,否则影响注册
phone_register_email_status：手机号注册时是否需填写邮箱。
tg_auto_login：telegram小程序自动注册登录。
is_show_user_protocol：用户协议和隐私协议是否显示。
register_give_money：注册赠送基础金额
register_give_experience_money：赠送投资体验金额
experience_money_expired_type：1.多少天未投资失效。2.投资多少次后失效
experience_money_expired_day：体验金多少天没参与投资自动失效
experience_money_expired_num：体验金投资多少次自动失效
experience_money_is_rebate：体验金投资上级是否可以获得投资返利
register_is_captcha：注册是否开启验证码。
is_register_message：注册是否要发送站内信。
is_repeat_password：注册时是否开启重复一遍密码（登陆密码及安全密码）。

邀请配置

is_need_spreader：推荐人可选择是否必填。
invite_link_type：邀请码类型。
invite_domain_type：邀请链接域名类型。当前用户访问域名则使用用户当前访问的域名；固定域名则从下方配置的域名列表中选取
invite_fixed_domains：固定域名列表，JSON格式存储，必须以https开头，且仅为域名（如 https://example.com），不能包含/、?、#等符号
invite_url_prefix_random:邀请链接前缀是否随机
recharge_num_valid_user：用户充值多少金额为有效用户
user_recharge_rebate：充值六级返利：格式必须是[1,2,3,4,5,6],1代表一级的返利,2代表二级的返利,3代表三级的返利,4代表四级的返利,5代表五级的返利,6代表六级的返利
recharge_rebate_num：1.每次充值都返，2.只有首充才返利，只返一次
recharge_rebate_type：1.根据下级充值金额返佣，2.根据当前用户等级解锁金额返佣。如果下级充值金额小于解锁金额，依旧使用下级充值金额
recharge_rebate_account：充值返利账户，1.基础账户，2.佣金账户
is_open_first_charge_rebate：首充送款开关。
首充送款配置类型：统一配置：只设置一个送款金额比例，区间配置可以设置多个不同区间赠送不同比例的金额
first_recharge_send_account：首充送款账户，1.基础账户，2.佣金账户
first_charge_rebate_min：首充送款条件：充值金额大于等于x（最低要求），设置0不限制金额
first_charge_rebate_percent：首充送款额度：自由设置百分比
first_charge_rebate_cap：首充送款额度：单次封顶设置，可选0不封顶
is_open_again_charge_rebate：复充送款开关。
again_charge_rebate_min：复充送款条件：充值金额大于等于x（最低要求），设置0不限制金额
again_recharge_send_account：复充送款账户，1.基础账户，2.佣金账户
is_open_again_charge_rebate：团队充值满额奖励开关。
give_team_brokerage_account：团队充值奖励账户，1.基础，2.佣金
give_team_type：充值奖励设置类型，1.单个设置只设置单个条件，2.区间设置可设置多个层级的奖励
give_team_brokerage_limit：下三级团队充值满多少奖励
give_team_brokerage_num：下级团队充值满额奖励多少
task_expired_time：任务过期时间，单位/分钟
level_upgrade_type：vip解锁方式，1.根据基础余额直接升级不扣钱，2.扣除基础余额，并返还之前等级解锁金额到佣金，3.扣除基础余额，不返还解锁金额。
level_upgrade_return_type：升级返还解锁金额类型，1.立即返还，2.等级到期还返。
level_valid_type：用户vip等级有效次数，1.按每24小时次数，2.按总次数。
auto_unlock_level：自动解锁会员等级。true自动，false手动
task_reset_type：任务重置方式。1.绝对24小时：今天这个时间做任务，明天的这个时间才可以再做；2.某个时间重置：所有人都固定在设定的时间才可以再做任务
show_data_time：网站当前使用的时区，请根据您的运营需要进行调整。

延后指当前重置时间将延后一天，不延后指重置时间直接改为今日的这个时间
task_num_show_type：任务数量展示类型。1:全部显示，2:只显示一个,做完才显示下一个
is_upgrade_reset_task：升级是否重置新的任务：比如会员充值VIP1做完任务后当天再充值VIP2是否要让他继续做任务。
vip_end_clear：等级到期是否归零：设置归零后，用户等级到期后自动变成等级0;如果升级方式选择根据基础余额直接升级不扣钱,那么基础账户的金额会直接清零
vip0_is_withdrawal：vip0是否可以提现。
vip0_task_brokerage_account：vip0做任务收益到账账户。
is_distribute_task：是否开启分配任务：关闭后全体用户都不能做任务。
basic_below_task_do：基础金额低于任务金额是否可以做任务
is_auto_check：分享是否自动审核。1自动，2手动审核。

操作流程：创建telegram机器人，然后创建群组/频道，将机器人拉入群组/频道后设置为管理员
extract_tg_msg_status：提现消息发送开关。

extract_tg_group_id：提现机器人群组/频道id。
extract_num_tg_msg：提现金额发送范围。支持区间如 100-10000；填单个数字（如 100）表示大于等于该金额才发送，兼容旧配置。
extract_tg_text：提现发送的消息内容。消息内容不超过4096个字符。可使用变量：{:num1} 代表转账哈希，{:num2} 代表出款金额。
extract_address_fake：自定义地址监听配置。每个地址可选择监听的链：1=TRON, 2=BSC, 3=Polygon, 4=ETH。
update_money_google_secret：修改用户余额,手动充值是否需要谷歌验证码。
edit_address_is_google：修改提款地址和出款安全值,提款次数,只允许一个提现通道,取款地址修改开关是否需要谷歌验证码。
edit_user_info_is_google：修改用户信息是否需要谷歌验证码。开启后修改用户的任何信息和批量修改等级都需要谷歌验证码
extract_check_is_google_code：提款审核是否需要谷歌验证码。
google_code_disallow_reuse：开启后同一验证码2分钟内不可重复使用，需等待下一分钟更新后使用新验证码。
